# Station 7 nutrunner faults
Practice note. Station 7 tightens the cover bolts with a nutrunner. When station 7 shows a nutrunner fault, read the code on the controller and check the vendor table before resetting. Most station 7 stops are an empty bolt feeder, not the nutrunner itself.
