# Learnings

One rule each, with its evidence.

- **Pick the permanent folder before building.** Evidence: 2026-11-13, the PC shared no folder with the cloud session, so Phase 1 was drafted in a repo and has to be copied over.
- **A check that can't fail proves nothing.** Run a negative control next to every check. (From the original build.)
- **A model refusing is not a block.** Test security boundaries by attacking them. (From the original build.)
- **Permission rules match text, not effects.** Enforce at the OS level when a command can reach any path. (From the original build.)
- **Render it; a type check is not a test of the page.** Evidence: 2026-11-15, the dashboard passed `tsc` and 22 tests, but a browser run showed an empty results box because `display: flex` overrode the `hidden` attribute.
- **Break a guard on purpose to prove its test.** Evidence: 2026-11-15, removing the path check, binding every address, and skipping the token check each made the suite fail, so the passing run meant something.
- **Read a flag's help before trusting its name.** Evidence: 2026-11-19, `--bare` looked like the way to strip inherited config, but it signs in only with an API key and would have broken every run on Jay's subscription login. `--restricted` plus `--strict-mcp-config` did the job without touching sign-in.
- **A secure setting can fail open by default.** Evidence: 2026-11-19, Claude Code's docs say that if the sandbox can't start it runs commands unsandboxed unless `failIfUnavailable` is set. The bridge sets it and also refuses Bash itself when no sandbox is detected.
- **A clean attack result is not proof until you know why it was clean.** Evidence: 2026-11-19, the Grep attack leaked nothing only because ripgrep skips hidden files, not because a rule blocked it.
- **Record the attempt before the action.** Evidence: 2026-11-19, the routine ledger is written before a run starts; a test that skipped this ran the same slot twice after a restart.
- **Count the worst case against a budget, then settle.** Evidence: 2026-11-19, a routine reserves its full budget before starting and swaps it for the real cost after, so the daily cap can't be crossed by runs that are still going.
- **Run code that ships with the program, not a copy the data folder could hold.** Evidence: 2026-11-20, the brain server path was built from the vault folder; a test vault with no code in it made the server silently never start. It now points at the bridge's own `brain/mcp.ts`.
- **A test marker can contain another marker.** Evidence: 2026-11-20, the stand-in's `DIAGHANG` contained `HANG`, so the run being tested hung instead of only its diagnosis, and the suite stalled. Markers are now distinct words.
- **Pick UI elements by exact name.** Evidence: 2026-11-20, a browser check clicked "Approve" and hit a department card whose text says "approves". The page was fine; the check was wrong.
- **A budget cap is checked after a turn, not mid-turn.** Evidence: 2026-11-20, a run capped at $0.0001 spent $0.0015 before stopping. Caps limit runaway spend; they aren't exact.
- **Check a path for links before you create anything under it.** Evidence: 2026-11-20, the session importer checked that `raw/sessions` stayed inside the vault only after `mkdir`, so a test with that folder linked out left an empty folder outside the vault before refusing. It now checks each folder before creating the next.
- **An eval every method aces cannot rank them.** Evidence: 2026-11-21, the first brain eval draft scored keyword search at hit@5 1.000, leaving no room to show whether embeddings help. Ten "synonym" questions (almost no shared words) brought it to 0.867, with synonym questions at 0.600.
- **Fusion can drop what only one list found.** Evidence: 2026-11-21, hybrid search raised MRR from 0.723 to 0.869, but "what should I do today" lost `wiki/directives.md`: keyword search found it, the vector list didn't, and notes found by both lists outranked it. Report the loss; don't tune the set to hide it.
- **Don't let a weak signal vote just because it is in the top N.** Evidence: 2026-11-22, every one of the top 50 meaning matches for "what should I do today" scored under 0.2 (noise for this model), yet each got a vote and they pushed the keyword hit out. A similarity floor of 0.15 brought it back to rank 3 and made no other eval question worse.
- **Compare paths the way each tool reports them.** Evidence: 2026-11-22, the first Windows CI run after the backup merge: `realpathSync` keeps Windows 8.3 short names (`RUNNER~1`) while git's `--show-toplevel` gives the long name, so a vault that was its own repo was refused as nested. Both sides now use `realpathSync.native`.
- **A test must name files the way the file system will.** Evidence: 2026-11-22, Windows CI: a test file called `has:colon.txt` became a hidden stream on a file named `has` (NTFS), and a test keyed by `path.relative` got `\` instead of `/`. Neither was a code bug; the tests now check the Windows behaviour and key on `/`.
- **Name a state by what it proves.** Evidence: 2026-11-22, `~/.superos/autostart.json` only meant "the plan was shown", so the Setup checklist could not tell "registered" from "previewed". `npm run autostart` now records `installed` only after Task Scheduler accepted the task.
- **Two layers can hide a broken one.** Evidence: 2026-11-21 to 22, removing the symlink check on a feed or log file left the suite green because a real-path check underneath still refused it; the mutation only failed once both were removed. Break each layer, or say that one is covered by the other.
