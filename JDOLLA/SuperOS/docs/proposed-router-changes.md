# Proposed router changes

A proposal for `JDOLLA/SuperOS/CLAUDE.md`. The vault's `.claude/settings.json` blocks Claude from editing that file, so the change is written here for Jay to review. Apply it, then delete this file.

## What it changes
1. **Brain first.** The router said the brain index doesn't exist yet. It has existed since 2026-11-20 (`docs/STATUS.md`), so the router now points to the `superos-brain` `search` and `get_note` tools, with the indexes as the fallback.
2. **`os/` row.** The rule "Phase 2" becomes "Read `docs/STATUS.md` and `docs/LEARNINGS.md` before changing it".
3. **Answers compound.** Durable answers are filed as wiki notes with their sources, and `last_used` is bumped on the notes used. This is the loop that makes the brain grow from use, not only from new uploads.
4. **Contradictions.** When a new source conflicts with a note, both claims are kept with their sources. Nothing is silently overwritten.
5. **Generated files.** Any file with the `os/vault` marker is changed through the generator, never by hand.
6. **Changing `os/`.** Adds the commands and a definition of done drawn from `docs/LEARNINGS.md`.
7. **Windows.** Adds a note that native Windows has no sandbox, so Bash runs need WSL2.
