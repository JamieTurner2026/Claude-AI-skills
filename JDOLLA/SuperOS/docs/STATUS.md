- Inbox triage (Phase 6e): built 2026-11-21. The Proposals widget shows how many files wait in `inbox/` and has a **Sort inbox** button. It starts one read-only T2 run at the T2 budget ($0.05; it does not count against the routine cap). The bridge builds the prompt: up to 25 file names, sizes and the first 800 characters of each, fenced as untrusted data (dot-files, `.env*`, links, folders, `README.md` and anything over 1 MB are skipped; the prompt is kept under the Windows command-line limit). The run answers in JSON (`[{file, dept, topic, reason}]`), which the bridge re-checks: the file must be one it offered, the department known, the topic a plain slug. Each valid suggestion becomes a learning-loop proposal of the new kind `move`, with Approve and Reject and the same decided-once rule (no diagnosis run, no cost).
  - **Approve is the only thing that moves a file**: the bridge re-checks the proposal, then moves exactly one regular file from `inbox/` into `raw/<known dept>/<slug>/` (real paths, no links, folders created only there, a name already taken becomes `-v2`, nothing is ever overwritten, nothing ever leaves `raw/`). It then logs `kind: inbox-move`, rebuilds the generated indexes and marks the brain index stale so the next run reindexes. Reject leaves the file where it is. A refused move leaves the proposal pending.
  - Routes: `GET /api/inbox`, `POST /api/inbox/sort` (same session, origin and header checks); approve and reject reuse `/api/proposals/:id/...`. 22 new tests.

- Local meaning search (7a): built 2026-11-21. Hybrid search adds a small local model (`Xenova/all-MiniLM-L6-v2`, quantized, CPU only, no API key) to the keyword index and merges the two rankings by reciprocal rank fusion. Vectors live in the same sqlite index. It's **opt-in**: nothing changes until `npm run brain -- index --embeddings`, the only command that downloads anything (a pinned runtime of about 400 MB plus a 23 MB model, into `~/.superos/brain/embeddings`, outside the vault). Once set up, the brain server uses hybrid for every run. If the model can't load, it logs a note and uses keyword search. `SUPEROS_BRAIN_HYBRID=off` forces keyword search.
  - **Eval on this vault, keyword → hybrid:** hit@1 0.633 → 0.833, hit@5 0.867 → 0.900, hit@10 0.900 → 0.933, MRR 0.723 → 0.869. At k=5 by style: keyword 1.000 → 1.000 (MRR 1.000 → 1.000), paraphrase 1.000 → 0.900 (MRR 0.850 → 0.900), synonym 0.600 → 0.800 (MRR 0.320 → 0.707).
