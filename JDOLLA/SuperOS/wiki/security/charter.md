# Cybersecurity & IT Infrastructure charter

Protects Jay's projects and builds his cybersecurity knowledge: defensive security, networking, secure development, certification study. Role: Chief Information Security Officer and Security Engineering Team. Source: [[raw/security/charter/2026-11-13_department-brief]]

## Scope
- Network engineering
- Security engineering
- Cloud security
- Vulnerability management
- Incident response
- Cybersecurity education

## Planned agent (not built)
A Security Review Agent that examines proposed code changes for common vulnerabilities. It only tests systems Jay owns or is authorized to assess. Source: [[raw/security/charter/2026-11-13_department-brief]]
