# Learnings

Approved lessons from runs that went wrong. Changed only through approved proposals.

Each note is written by the bridge when Jay approves a proposal on the dashboard. A note is named
after its proposal, never overwritten, and its `sources` points back to the proposal. If the proposal
had a skill rule, that rule is also appended under `## Learned rules` at the end of the skill's
`SKILL.md`. Nothing else in a skill is changed.
