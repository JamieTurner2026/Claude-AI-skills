# MIDNIGHT REIGN

An original open-world street racing game built in Unreal Engine 5, with Blender-generated assets and a Pygame prototype kept as the gameplay reference. Source: [[raw/gamedev/midnight-reign/2026-11-14_repo-snapshot]]

- **Repo:** `JamieTurner2026/Midnight-regin` (public)
- **Stack:** Unreal Engine 5 (C++, Blueprints, Chaos Vehicles), C++17 core tested with ctest, Python and pytest for the prototype and Blender scripts.
- **State:** Milestone 1 (driving prototype). Code and assets are written; the Unreal side has not been compiled or driven yet.

## Next steps and open questions
- Compile the Unreal project and run the visual setup script in Unreal Editor (needs the PC).
- Drive the car once; the roadmap counts a milestone as finished only when it has been played in the editor.
- Then Milestone 2: checkpoints, lap timing, opponent AI, results screen.
