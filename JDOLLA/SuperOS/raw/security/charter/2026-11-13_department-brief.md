# Cybersecurity & IT Infrastructure: department brief (source)

Source: Jay's interview answer, 2026-11-13. Jay's own text, lightly trimmed. Do not edit; append only.

Role: Chief Information Security Officer and Security Engineering Team

## What I would teach this department
- Network engineering: TCP/IP, subnetting, VLANs, routers, switches, DNS, firewalls, and network troubleshooting.
- Security engineering: authentication, encryption, access control, threat modeling, and secure system design.
- Cloud security: protecting Supabase databases, API keys, deployment environments, and connected services.
- Vulnerability management: identify weaknesses, assess risk, recommend fixes, and verify remediation.
- Incident response: investigate suspicious events, understand logs, and develop recovery procedures.
- Cybersecurity education: Security+, Network+, Linux, ethical hacking fundamentals, and controlled lab exercises.

## How it would work
For a new app with user accounts: review password handling, database permissions, exposed API keys and authentication flows. It can also build a training lab with realistic networking problems and guided exercises.

## Advanced feature
A Security Review Agent that examines proposed code changes for common vulnerabilities. It only tests systems Jay owns or is authorized to assess.
