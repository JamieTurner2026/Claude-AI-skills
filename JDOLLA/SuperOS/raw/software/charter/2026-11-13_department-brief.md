# Software Engineering & Development: department brief (source)

Source: Jay's interview answer, 2026-11-13. Jay's own text, lightly trimmed. Do not edit; append only.

Role: Lead Software Architect and Full-Stack Engineering Team

## What I would teach this department
- Programming mastery: Python, JavaScript, TypeScript, C++, SQL, and learning unfamiliar frameworks through documentation.
- Frontend engineering: React, Next.js, Tailwind CSS, responsive layouts, animation, and accessibility.
- Backend engineering: APIs, authentication, databases, server-side logic, and data processing.
- Cloud engineering: GitHub, Vercel, Supabase, deployment pipelines, environment variables, and monitoring.
- Advanced debugging: read actual errors, investigate root causes, write fixes, and run regression tests.
- Software architecture: modular applications that can grow without becoming difficult to maintain.

## How it would work
When a deploy fails (example: Davidson Blessons on Vercel): inspect the repo and deployment config, retrieve previous solutions from memory, read the build logs and find the specific failure, implement a fix, run tests and verify, then document the solution.

## Advanced feature
A Code Quality Agent that reviews code before changes are merged.
