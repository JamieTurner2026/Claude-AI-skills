# Blender and Unreal Engine skills

Goal: build polished visuals and enjoyable gameplay in Blender and Unreal Engine 5.8.4.

- Start with unreal-blueprints for a playable interaction and unreal-enhanced-input for controls.
- Refine the scene with Blender's existing model, realism, and export workflows. Check silhouettes, scale, materials, lighting, and collision after import.
- Use unreal-niagara for effects that clarify player actions. Use unreal-behavior-trees for AI, unreal-cpp-gameplay for reusable code, and unreal-packaging to test a standalone build.
- MPFB2 can supply Blender character bases. The source ZIP is at the workspace root as mpfb2-source.zip. For installation, use the Blender extension listing and check the supported Blender version. Test one character's scale, rig, materials, and animation before using it across a project.
- First test: build one short playable sequence with one clear goal, check the controls and effects in play, then capture a render and test a packaged build.

The six skill folders are reference copies from https://github.com/Skyrant/gamedev-agent-skills/tree/main/skills/unreal. Check for duplicates against Claude-AI-skills before importing. MPFB2 source: https://github.com/makehumancommunity/mpfb2. Existing Blender workflows: ../../patterns/blender-to-unreal/recipe.md and ../../patterns/blender-realism-review/.
