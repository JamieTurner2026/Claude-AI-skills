# MIDNIGHT REIGN

Original open-world street racer. UE5 C++ in `unreal/MidnightReign`, engine-independent gameplay
maths in `core/`, original Pygame prototype in `prototype/python`.

## Commands
- Core tests: `cmake -S core -B build && cmake --build build && ctest --test-dir build --output-on-failure`
- Python tests: `pytest prototype/python`
- Assets: `python3 blender/build_all.py` then `pytest blender/tests` (needs `pip install bpy`); previews: `python3 blender/render_previews.py all`
- Unreal cannot be compiled in cloud sessions; it is built in the user's Unreal Editor (5.6+).

## Rules
- Never edit `prototype/python/midnight_street_racer.py`; it is the preserved reference.
- Gameplay rules that can be expressed without Unreal go in `core/` with tests; Unreal classes wrap them.
- Unreal classes use the `MR` prefix, expose state/events to Blueprints, and take values from data
  assets (`UMRVehicleTuningData`) rather than hardcoding per-car numbers.
- Keep gameplay logic out of UI classes; UI only reads state.
- Do not describe Unreal code as working unless it was compiled and run; say "written, not compiled".
- Credits, XP, ownership and scan results must be server-authoritative (later milestones).
- Use only original or properly licensed vehicle assets and fictional city/vehicle names.
- Secrets: never commit `.env*` except `.env.example`.
- 3D assets are generated by `blender/` scripts following `docs/art-pipeline.md` (cm units, +X forward, `M_MR_*` slots, `Phys_Wheel_*` bones); look at the preview renders before calling a visual done.
- Milestones are done one at a time; see `docs/roadmap.md`.
