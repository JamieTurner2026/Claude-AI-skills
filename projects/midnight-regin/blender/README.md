# Blender asset pipeline

Every 3D asset in `assets/export` is generated by these scripts, so it can be rebuilt, changed
and tested without opening Blender's interface.

```bash
pip install bpy pytest
```

```bash
python3 blender/build_all.py
```

```bash
pytest blender/tests
```

```bash
python3 blender/render_previews.py all
```

`bpy` is Blender as a Python module (version 5.x needs Python 3.11 or 3.13). The same scripts run
inside a normal Blender install: `blender -b -P blender/build_all.py`.

| File | What it does |
|---|---|
| `specs/solaris_gt.json` | Data for the starter car: body sections, wheelbase, wheel sizes, sockets, colours |
| `build_vehicle.py` | Spec → rigged car (`Root` + four `Phys_Wheel_*` bones) → `SK_*.fbx` + manifest |
| `build_parts.py` | Wheels, spoilers, splitter, diffuser as static meshes with attach-point origins |
| `build_track.py` | Solaris Coast test block + `track_layout.json` (checkpoints, player start) |
| `build_all.py` | Runs the three builds and writes `materials.json` |
| `render_previews.py` | Renders `docs/previews/*.png` (`--quick` for fast drafts) |
| `lib/` | Shared helpers: units, materials, lofting, FBX export, rendering; part builders |
| `tests/` | Re-imports every FBX and checks what Unreal and the C++ rely on |

Conventions are in `docs/art-pipeline.md`.
